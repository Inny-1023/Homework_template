# SPIN — 생각 세탁소

첨부된 콘셉트 B를 바탕으로, 빨래를 처리하는 동작으로 메모의 상태를 관리하는 데스크톱 웹 프로토타입입니다.

## 실행

이 폴더에서 `npm start`를 실행하고 `http://localhost:4186`을 여세요. 설치와 빌드가 필요하지 않습니다.

## 동작

- 화면에는 바구니·세탁기·건조대 중 한 공간만 보입니다. 옆으로 스와이프하거나 트랙패드, 이전/다음 화살표, 단계 탭으로 넘깁니다.
- 메모를 잡은 채 위 단계 탭이나 화면 양쪽 끝에 잠시 올리면 다른 공간으로 이동합니다. 탭은 화면만 넘기며 메모 상태를 바꾸지 않습니다.

- 새 메모를 작성하면 옷 한 벌이 생각 바구니에 들어갑니다.
- 옷 위의 점 손잡이를 끌어 직접 할 일, 건조대, 나중에 참고할 생각으로 분류합니다.
- 세탁기 화면에서 둥근 문을 눌러 열고, 옆의 티셔츠를 열린 원형 드럼 안으로 끌어 놓으면 문이 닫히고 작업이 시작됩니다. 닫힌 문·세탁기 본체·드럼 바깥·탭에 놓으면 시작되지 않습니다. 한 번에 하나만 작업할 수 있습니다.
- 잠시 멈추면 직접 할 일로 돌아갑니다. 끝내고 접으면 완료 보관함으로 이동합니다.
- 보관한 옷의 밑단을 내려 펼치면 원문과 상태 변경 기록이 보관함 안에 직접 표시됩니다. 내용 수정은 펼쳐진 원문의 수정 기능을 이용합니다.
- 화면에 놓인 옷의 실제 밑단을 위로 끌면 소매와 밑단이 연속해서 접힙니다. 충분히 접은 뒤 손을 놓으면 완료 보관됩니다.
- 접힌 옷의 실제 밑단을 아래로 끌면 그 자리의 옷이 펼쳐지고 원래 메모와 작업 기록이 옆에 보입니다. 별도 창이나 미리보기 옷을 만들지 않습니다. 읽기 위해 펼치는 동작은 완료 상태를 유지합니다. 재작업하려면 원문 화면에서 바구니 또는 직접 할 일로 옮깁니다.
- 덜 끌고 놓기, Esc, 포인터 취소는 실제 상태를 바꾸지 않습니다. 옷 밑단에 초점을 맞추고 위·아래 방향키로 조작하거나 Enter로 완료할 수 있습니다.
- 드래그 대신 메모 안의 이동 버튼을 쓰거나, 손잡이에서 방향키로 위치 선택 후 Enter로 이동합니다.
- 이동·삭제·수정은 알림의 되돌리기로 취소할 수 있습니다.

## 저장

메모는 현재 브라우저의 localStorage에 저장됩니다. 계정 동기화와 서버 알림은 없습니다. 처음 실행하면 예시 메모 6개가 표시됩니다. 브라우저 데이터를 지우면 메모도 삭제됩니다.

## 확인

`npm test`는 상태 이동, 단일 작업 제한, 완료 후 재개, 원문과 기록 보존, 저장 및 복원 동작을 검증합니다.
